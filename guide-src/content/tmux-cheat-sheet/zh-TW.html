用 tmux new -s work 建立命名 session，按 Ctrl+b d 暫時脫離而不中斷程式，用 tmux ls 列出所有執行中的 session，再用 tmux attach -t work 接回畫面。以下指令在 macOS 與 Linux 透過 SSH 皆可直接使用。

這頁是 tmux 原理說明 的隨查速查表。把最常用的幾行存起來；如果是從手機操作，也可以直接用點選取代輸入前綴組合鍵。

Session：建立、列表、接回、脫離

Session 是在 SSH 斷線後仍留在遠端機器上的單位。建議以專案名稱或任務命名，tmux ls 才不會只剩一排數字。

目的 指令 說明
建立命名 session tmux new -s work 建立名為 work 的 session 並立刻進入
存在就接回、沒有就建立 tmux new -As work 最適合寫進捷徑或常用指令的單行寫法
列出目前所有 session tmux ls 顯示名稱、window 數量與是否已連線
接回既有 session tmux attach -t work 簡寫：tmux a -t work
暫時脫離（背景繼續跑） Ctrl+b d 回到外層 shell，裡面的 agent 不會停止
重新命名目前 session Ctrl+b $ 輸入新名稱後按 Enter
關閉已結束的 session tmux kill-session -t work 結束 work 裡的所有 window 與 pane

Window 與 Pane 操作

先按 Ctrl+b 並放開，再按後面的功能鍵。在同一個 session 裡，window 像分頁，pane 則是把單一視窗分割成多塊。

動作 快捷鍵
新增 window Ctrl+b c
切換上一個 / 下一個 window Ctrl+b p / Ctrl+b n
重新命名目前 window Ctrl+b ,
上下分割 pane Ctrl+b "
左右分割 pane Ctrl+b %
在 pane 之間移動 Ctrl+b 後按方向鍵
放大 / 還原目前 pane Ctrl+b z
關閉目前 pane 輸入 exit 或按 Ctrl+d

在手機螢幕上，分開建立獨立 session 或用 Ctrl+b z 放大單一 pane，會比左右並排分割好讀很多。

捲動畫面與複製模式

在 tmux 裡直接滑動終端機通常捲不動歷史輸出，必須進入 copy mode 或開啟滑鼠模式。

  • 進入捲動 / 複製模式：按 Ctrl+b [，之後可用方向鍵、PageUp 或輸入 / 往上搜尋文字。
  • 離開複製模式：按 q 或 Esc 回到即時輸入列。
  • 視覺化切換 session：按 Ctrl+b s，用方向鍵挑選想接回的 session。

給 SSH 與手機使用的精簡 ~/.tmux.conf

在遠端主機的 ~/.tmux.conf 加入這四行，再執行 tmux source-file ~/.tmux.conf 生效：

set -g mouse on
set -g history-limit 10000
set -sg escape-time 10
set -g focus-events on
  • mouse on 讓觸控捲動與點擊切換 pane 透過 SSH 也能運作。
  • history-limit 10000 保留足夠的歷史輸出，方便回看 agent 的長段 diff 與測試結果。
  • escape-time 10 消除在 Vim 或 CLI agent 按 Esc 時的延遲感。
  • focus-events on 讓編輯器與終端工具能偵測你何時切回畫面。

在手機上略過前綴快捷鍵

在手機虛擬鍵盤上反覆按 Ctrl+b 組合鍵很花時間。Agentmux 會在連線時自動列出執行中的 tmux session、點一下就能接回，並提供 14 天全功能試用與免費單一伺服器方案。如果主機還沒設定好，可以先跑一遍 設定精靈。

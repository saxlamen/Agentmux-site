用 tmux new -s work 创建命名 session，按 Ctrl+b d 暂时脱离而不中断程序，用 tmux ls 列出所有运行中的 session，再用 tmux attach -t work 接回画面。以下命令在 macOS 与 Linux 通过 SSH 均可直接使用。

这页是 tmux 原理说明 的常用速查表。把高频几行存下来；如果是从手机操作，也可以直接点选来代替输入前缀组合键。

Session：创建、列表、接回、脱离

Session 是在 SSH 断线后仍留在远程机器上的单位。建议按仓库名或任务命名，这样 tmux ls 才不会只剩一排数字。

目的 命令 说明
创建命名 session tmux new -s work 创建名为 work 的 session 并立刻进入
存在就接回、没有就创建 tmux new -As work 最适合写进快捷指令或脚本的单行写法
列出当前所有 session tmux ls 显示名称、window 数量与是否已连接
接回已有 session tmux attach -t work 简写：tmux a -t work
暂时脱离（后台继续跑） Ctrl+b d 回到外层 shell，里面的 agent 不会停止
重命名当前 session Ctrl+b $ 输入新名称后按 Enter
关闭已结束的 session tmux kill-session -t work 结束 work 里的所有 window 与 pane

Window 与 Pane 操作

先按 Ctrl+b 并松开，再按后面的功能键。在同一个 session 里，window 像标签页，pane 则是把单个窗口拆分成多块。

动作 快捷键
新建 window Ctrl+b c
切换上一个 / 下一个 window Ctrl+b p / Ctrl+b n
重命名当前 window Ctrl+b ,
上下拆分 pane Ctrl+b "
左右拆分 pane Ctrl+b %
在 pane 之间移动 Ctrl+b 后按方向键
放大 / 还原当前 pane Ctrl+b z
关闭当前 pane 输入 exit 或按 Ctrl+d

在手机屏幕上，分开创建独立 session 或用 Ctrl+b z 放大单个 pane，会比左右并排分屏好读得多。

滚动画面与复制模式

在 tmux 里直接滑动终端通常滚不动历史输出，必须进入 copy mode 或开启鼠标支持。

  • 进入滚动 / 复制模式：按 Ctrl+b [，之后可用方向键、PageUp 或输入 / 向上搜索文本。
  • 退出复制模式：按 q 或 Esc 回到实时输入行。
  • 可视化切换 session：按 Ctrl+b s，用方向键挑选要接回的 session。

适合 SSH 与手机的精简 ~/.tmux.conf

在远程主机的 ~/.tmux.conf 加入这四行，再执行 tmux source-file ~/.tmux.conf 生效：

set -g mouse on
set -g history-limit 10000
set -sg escape-time 10
set -g focus-events on
  • mouse on 让触控滚动与点击切换 pane 通过 SSH 也能生效。
  • history-limit 10000 保留足够的历史行数，方便回看 agent 的长段 diff 与测试输出。
  • escape-time 10 消除在 Vim 或 CLI agent 按 Esc 时的延迟感。
  • focus-events on 让编辑器与终端工具能检测你何时切回窗口。

在手机上跳过前缀快捷键

在手机虚拟键盘上反复按 Ctrl+b 组合键很慢。Agentmux 会在连接时自动列出运行中的 tmux session、点一下就能接回，并提供 14 天全功能试用与免费单服务器方案。如果主机还没配好，可以先走一遍 配置向导。

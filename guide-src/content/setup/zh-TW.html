把 agent 放到遠端整晚跑，大約 15 分鐘：用 SSH 連進你自己那台機器，用 tmux 讓手機斷線時只是 detach、不會停止 agent，再用 Tailscale，就不用對公網開 port。回答三個問題：你的機器、要跑的 agent、你想從哪裡連。清單會照你的答案生成。

每一步都會告訴你為什麼要做、指令是什麼、怎麼確認成功了，還有沒成功的話去哪裡看。（那台機器是 Windows？先看這一節。）

那台機器是 Windows

選「一台 Windows 電腦」，精靈會跟其他答案一樣給你清單：打開 SSH 伺服器、別讓電腦睡、裝你的 agent，psmux 它會自己處理。這一節處理兩件從別條路過來的人一定會卡住的事：Windows 上取代 tmux 的是什麼，還有你在別處讀過的 WSL2 現在還要不要走。

先講結論：Windows 10 和 11 都有 OpenSSH Server，用 PowerShell 打開就好。撐住 session 的是 psmux：指令照 tmux 那套設計，為 Windows 寫的。那台機器沒裝的話，Agentmux 會幫你裝。不用 WSL2、不用虛擬機，也不用轉 port。指令、Windows 的 session 能做什麼、跟 Linux 主機哪裡不一樣，全部在這篇 Windows 主機指南。

想要的是 Linux 那個生態而不是一台 Windows，就繼續用 WSL2。WSL2 裡面是完整的 Linux，「Linux 主機」那條路照樣適用，回去把第一題改成「一台 Linux 主機」。它附帶三個 Mac 沒有的坑：sshd 躲在虛擬機的 NAT 後面、WSL 最後一個程序結束後幾秒發行版就關掉、舊版預設沒有 systemd。三個坑的解法寫在那篇 WSL2 那一節。

如果 Windows 只是你工作用的那台電腦呢？

這裡講的 Windows，指的從來是「那台被連進去的機器」。如果你的 Windows 只是你平常工作的電腦，agent 跑在別台上（家裡的 Mac mini、公司的 Linux 主機、一台 VPS），那上面這些你一個都不會遇到，這份指南對你完全成立。你要設定的機器，不是你手上這台。

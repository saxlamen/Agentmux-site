汎用 SSH クライアントはコマンドを入力するために開く前提で作られていますが、Agentmux はすでに動いているエージェントへ戻るために開く前提で作られています。Mosh、SOCKS5 フォワーディング、プラットフォーム間のホスト設定同期が必要なら Termius や Blink を選んでください。複数のサーバーで動くコーディングエージェントを扱うなら、Agentmux が適しています。

どちらも SSH で接続し、プロンプトを返します。違いを生むのは再接続に対する設計の深さであり、以下の比較表のすべての項目はその一点から導かれます。記載している 5 つの機能は、いずれも現在のソースコードと照合して確認済みです。

前提が異なる 2 つのツール

汎用 SSH クライアントはホストとシェルを中心に設計されています。使えるプロンプトを出したら、その先で何が起きるかはユーザー次第です。

Agentmux はどこかですでに動いているエージェントを中心に設計されています。ポケットからそのプロセスまでの距離を縮めることが役割です。そこから 3 つの違いが生まれ、後半の 2 つは優れた汎用クライアントでも代替できない領域です。製品として想定している用途が異なります。

  • 最初に目に入るもの。ホストの一覧か、その上で動いているセッションの一覧か。
  • 回線が切れたときの代償。移動し直すプロンプトか、離れたときと同じ画面か。
  • アプリを閉じている間の振る舞い。何もしないか、ロック画面の進捗表示と終了時の通知音か。

なぜ Agentmux は最初に tmux セッションを並べるのか

サーバーに接続すると、Agentmux はその上で動いている tmux セッションを一覧表示します。1 タップで再アタッチできるため、tmux ls を打ったり tmux attach -t のセッション名を覚えたりする必要がありません。回線が切れて再接続しても、同じセッションの離れたときと同じ画面にそのまま戻れます。

エージェントの価値は、読み込んだファイルや方針を選んだ理由といった蓄積されたコンテキストにあります。その画面に戻ればコンテキストは保たれますが、新しいプロンプトを開けば記憶を持たないプロセスに最初から説明し直すことになります。tmux の役割は、この設計を支える土台です。

画面を見ていない間にアプリは何をするか

エージェントが十数分から数十分動き続けることは珍しくなく、その待ち時間を前提に設計されています。Dynamic Island とロック画面に進捗が表示され、実行が終わると通知音で知らせます。アプリをフォアグラウンドに開いたまま見張り続ける必要はありません。

シェルを中心に作られたアプリは、閉じられると「実行中のジョブ」という概念を持たないため何も報告できません。Agentmux では名前付きのサーバー上で名前付きのセッションが動いており、システムがその状態を報告します。コマンド実行の許可を求めて停止したときは、AI 自動権限レビューが先に確認します。危険なコマンドは保留し、安全なコマンドにはキーの提案または自動入力を行います（Pro）。

vim を開かずにファイルを編集できるか

コードを 1 行直すために、スマホのキーボードで vim と格闘する必要はありません。内蔵の Runestone エディタでファイルを開いてそのまま編集できます。エージェントが生成した README は、Ink による 2 カラムの Markdown プレビューでソースと描画結果を並べて確認できます。

Git ツール（ブランチ切り替え、diff の閲覧）とファイルアプリ連携は Pro 機能ですが、14 日間の無料トライアル期間中も利用できます。エージェントがファイルを変更し、こちらが diff を読んで指示を返し、またエージェントが進めるというループが 1 台の端末で完結します。別のマシンが必要になる作業まで机に戻るのを待つ必要はありません。

秘密鍵はどこに保存されるか

秘密鍵は OS ネイティブのセキュアストレージ（iOS の Keychain、Android の Keystore）に保存され、ローカルデータベースには一切保存されません。iOS で iCloud 同期をオンにした場合でも、CloudKit で同期されるのはサーバー名などの機密ではないメタデータだけです。秘密鍵は端末の外に出ません。

どのツールを使う場合でも、「同期をオンにしたとき、自分のどの秘密鍵が端末の外に出るのか」と同じ質問をしてみてください。機能一覧表だけでは、その答えはわかりません。

Siri からショートカットへ画面を渡す

GetCurrentSessionContextIntent を使えば、Siri に「Agentmux から現在のターミナル内容を取得」と話しかけるだけで、画面に表示されている内容が iOS のショートカットに渡り、メモやメッセージなど任意のフローへ送れます。ContinueLastSessionIntent はさらに直接的で、「Agentmux で作業を続ける」と伝えるだけで直前のセッションに再アタッチします。

汎用 SSH アプリには構造的にこれができません。セッション、プロジェクト、エージェントといった意味モデルをシステムに公開していないためです。Agentmux は Server、Project、TMUXSession、RecentSession の 4 つのエンティティ型に対して 6 つの App Intents を実装しています。

日本語・中国語・韓国語を読む人が気づく修正

バージョン 1.3.10 では、英語しか使わない人には気づかれにくいものの CJK テキストを読む人にはすぐわかる 3 つの問題が修正されました。全角文字で選択範囲がずれる問題、行をまたいで折り返されたリンクをコピーすると複数行に分断される問題、CJK テキスト内の単独のスラッシュがファイルパスとして誤認識される問題です。

用途別の選び方

1 台のホストでの手動ターミナル作業が中心のとき。サービスの再起動、ログの tail、ディスク容量の確認など、自分で選んだコマンドを打つためにログインするなら汎用 SSH クライアントが向いています。まず試してみたい場合は、無料のシングルサーバープラン（サーバー 1 台、永続セッション、基本ターミナル）が使えます。

複数サーバーでエージェントを動かしているとき。Mac mini でリファクタリングを進めながら、Linux マシンでテストを回し、移動中の電車から 3 台目を起動する。こうした使い方には Agentmux、特に Pro プラン（複数サーバー、カスタムエージェント、リモート編集、ファイル履歴、ブランチ操作、一括操作）が合います。

ブラウザのタブやクラウドサンドボックス上のエージェント。手軽さは確かですが、コードや認証情報を自分のマシン以外に置くことになります。Agentmux は作業環境をホストしません。

Agentmux はあくまでクライアントであり、コードもエージェントもあなたが所有する Mac、Linux マシン、またはサーバー上に留まります。プロジェクトや鍵をクラウドに置くことを許容できるなら、クラウドを借りる選択も合理的です。

接続経路には Tailscale を推奨します。インターネットにポートを開放する必要がなく、MagicDNS 名や 100.x アドレスで接続できます。

Termius の方が適しているケース

主な用途が次のいずれかに当てはまる場合は、汎用 SSH クライアントを選んでください。

  • 非常に不安定なモバイル回線で接続を維持するために Mosh が必要なとき。Agentmux は標準 SSH を使い tmux の自動再アタッチで補いますが、Mosh とは仕組みが異なります。
  • リモートまたは動的（SOCKS5）ポートフォワーディングが必要なとき。Agentmux が対応しているのはローカルフォワーディングのみで、機能上の制約です。
  • iOS、Android、Windows、macOS、Linux の間で大規模なホスト設定を同期したり、チームでホスト一覧を共有したりしたいとき。Agentmux はモバイル専用クライアントであり、Pro で複数サーバーや一括操作には対応していますが、共有機能はありません。
  • 数十台・数百台のサーバーを運用する SRE やシステム管理者のとき。画面をタップして選ぶリストよりも、スクリプトで扱えるインベントリの方が適しています。

Agentmux は「動いているコーディングエージェントにスマートフォンから戻る」という 1 つのワークフローに特化して作られています。汎用的な運用管理ツールではありません。日々の作業が単発コマンドの連続であれば、乗り換える理由はありません。

iPad でのキーボード作業と iPhone での確認

iPad と外付けキーボードを持ち歩き、不安定な Wi-Fi 下で長時間そのままリモートシェルを叩くなら Blink や Termius の Mosh が活きます。一方で iPhone から席を離れたあとに進捗を確認し、Claude Code や Codex の確認プロンプトに答えて差分を少し見る使い方なら、セッション一覧から即復帰できる設計の方が手間を減らせます。

Agentmux を使うと決めたら、次に整えるのは接続先のマシンです。セットアップウィザードで 3 つの質問に答えると手順チェックリストが生成されます。その後のつまずきやすい点は トラブルシューティング にまとめてあります。

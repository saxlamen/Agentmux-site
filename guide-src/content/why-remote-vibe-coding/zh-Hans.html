CLI agent 真正的成本是待命，不是打字：你讲三十秒，接下来几个小时不能离开座位。把它跑在你从来没关过的机器上，用 tmux 让 session 掉线照跑，再用 SSH 加 Tailscale 从手机接回去，待命就变成一部手机加十五秒，而它在你睡觉的时候继续工作。

如果你已经在用 Claude Code 或 Codex，大概感受过这件事：干活的是它，被绑住的是你。会被绑住不是因为你不肯放手，是因为那个 agent 只住在你这台机器上的一个窗口里。

时间花到哪里去了？

一轮 CLI agent 的工作，节奏几乎都是同一个样子：

你讲 30 秒 → 它跑 5–20 分钟 → 它需要你决定一件事 → 重复

把一整天的比例摊开来看，吃掉时间的不是打字。你描述需求那 30 秒，是全程最短的一截。剩下全是等：等它读完项目，等它改完十几个文件，等测试跑完。然后它停下来问：“这个 migration 要不要顺便处理？”你回一句话，接着又等五分钟、二十分钟。

一天下来，你真正打字的时间可能不到十分钟，被占掉的是好几个小时。这几个小时你在待命：什么都没做，但不能走开，因为它随时可能要你回一句话。

传统做法把待命绑死在一台笔记本上

这种待命有一个物理位置。agent 跑在你笔记本的终端窗口里，窗口连着那个 shell，shell 连着那台不能关掉的机器。于是你只有两个选择：

坐着等。人留在椅子上，盯着那个大部分时间什么都不发生的画面，只为了在它问的时候三十秒内回话。一小时换三句回复。

或者关掉笔记本。合上盖子，进程被停掉或直接死掉，session 没了，agent 积累下来的上下文也一起消失：它读过哪些文件、改到哪一步、为什么选这个做法。晚点回来只能重开一个，整段重讲一次，从头跑。

两个选择付的是同一笔代价。真正绑住你的是那台机器在哪里，不是工作本身。

哪三个零件解开这个绑定？

这个绑定不是一整块，是三层叠起来的。每一层都有现成的标准工具可以拆，而那些工具都已经存在几十年了。单独看，三样都很普通；叠起来才是重点：

零件解开的绑定
CLI agent 是纯文本进程，不需要图形界面 → 可以住在别台机器上
tmux session 钉在服务器上，掉线照跑 → 待命不需要你在场
SSH + Tailscale 从任何网络安全接回，不开公网端口、不需固定 IP → 待命不绑定设备与位置

顺序不能换。先有 CLI，agent 才可能离开你的笔记本，搬到家里那台从来没关过的 Mac mini 上。接着是 tmux，session 钉在那台机器上，你的连接断开它照样跑。最后是 SSH 加 Tailscale，你才能从地铁上、从公司、从别人家的 Wi-Fi 接回同一个 session，而且不用在路由器上开任何一个对外的端口。

少任何一个都不成立。只有 CLI 没有 tmux：一掉线，agent 就死。有 tmux，没有安全的接入方式：你只能在家里用它。

待命的成本是一部手机加十五秒

三层都拆掉之后，待命的代价从一台笔记本加一个固定位置，降到一部手机加十五秒。要确认它跑到哪里，你不用再找桌子、座位和电源。

只要十五秒，你就不用再排一段时间来盯它。排队看一眼，等红灯看一眼，睡前看一眼，回一句“用第二个方案”，手机收回口袋，agent 继续往前跑。

待命一旦不需要你在场，工作就能排进你本来就不在场的时间。丢一个重构任务给它，去吃晚饭。睡前开一个修测试的 session，早上起床看结果。那台机器每一个晚上本来都闲着。

还有其他做法能接到自己的 agent 吗？

要从远程接到自己的 agent，路不止一条。把这些做法放在同一组标准下比，差别就很清楚，尤其是最后一栏。多数人是事后才发现自己卡在那一栏。

做法 待命成本 上下文存活 需要的网络设置 能不能真的改文件
带着笔记本 要带一个包、找座位、找电源 合上盖子就停 不用，但机器得跟着你走 能，改的是本机的文件
VNC 远程桌面 需要一块够大的屏幕，还要用手指操作鼠标 UI 桌面 session 留着就活着 要打通 VNC 或另外架 VPN 能
网页版 agent 低，开浏览器就好 活在对方的服务器上 不用 改的是云端沙盒里的副本，不是你机器上那份
Codespaces 这类云端环境 低，但要能开浏览器 闲置久了容器会被回收 不用，但要把项目放上云端，并按用量计费 能，但改的是云端容器里的那份 repo
通用 SSH App 手机就行 靠 tmux，撑得住 要自己处理安全连外 能，但界面是把桌面终端直接搬过来
Agentmux 手机，十五秒接回 tmux 在服务器上，跟手机在不在无关 Tailscale，不开公网端口 能，改的就是你自己机器上那一份

跑在别人云端沙盒里的 agent，改的永远是一份副本：你的 .env 不在那里，今天早上装的那个内部包不在，那个只有本机跑得起来的数据库也不在。

走 SSH 加 tmux 这条路，agent 就坐在你自己的机器上，用你的环境，改你的文件。唯一的差别是这一次换你的手机看着它。

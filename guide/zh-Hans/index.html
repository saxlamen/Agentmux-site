我没开过终端

会用 AI 写代码，但没碰过 SSH。从终端是什么开始。

  1. 你的 AI 应该在你睡觉时工作
  2. 为什么不是 Cursor / VS Code
  3. 为什么最强的 coding agent 都住在终端里
  4. SSH：通往另一台电脑的隧道
  5. 让 agent 在你关掉手机后继续跑
  6. 不要对公网开端口
  7. 为什么不是 Termius / Blink
  8. 15 分钟，让你的 agent 开始整晚工作
  9. 你的 Windows 电脑也可以当主机
  10. AI 自动权限审查：agent 问你时，谁来回答

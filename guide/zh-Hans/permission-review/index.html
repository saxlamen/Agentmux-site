AI 自动权限审查：agent 问你时，谁来回答

AI 自动权限审查替你回答 agent 的权限提示：黑名单先拦下危险命令，白名单放行你已经信任的命令，两边都没命中的才交给 AI 判断。判断为允许时，顾问模式给你建议，自动回复模式帮你按下那个键。

agent 跑到一半停下来问「要不要执行这条命令？」，而你刚好不在屏幕前，整个任务就卡在那里，等这一个按键。

AI 自动权限审查就是为这一刻做的。它回答 agent 的提示，一次只按一个键，不会替你敲命令，也不会去碰画面上以外的东西。

agent 停下来等你，审查才开始

Agentmux 本来就会识别 Claude Code、Codex 这类 agent 的状态。画面出现「要不要允许」或「选 1 还是 2」这种提示时，它就把那个会话标记成等待中，审查从这一刻开始。

同时要符合这几个条件：

  • 「设置」里的 AI 自动权限审查开关是开的。
  • 这个会话选了「顾问」或「自动回复」模式，不是「关闭」。
  • 你是 Pro 用户，或还在试用期内。

同一个提示只会判断一次，不会每隔几秒重问一遍。你自己在终端里按了键或打了字，Agentmux 就取消还在进行的判断，以你的操作为准。

你切到别的标签页之后，它在后台继续帮你看着那些不在画面上的会话。

它只读当前画面上那一个提示

它先从画面上找出当前那一个提示：要执行的命令、问题本身，还有可以选的选项。已经滚上去的旧内容不算数。

发给 AI 之前，它会先把画面里看起来像密码、API key、token 的内容脱敏掉。脱敏失败时，原始内容不会发出，这一次也不帮你按任何键。

黑名单永远先跑，而且就在手机上

黑名单在你的手机上比对，永远第一个检查。命中就不会发给 AI，直接交给你处理。内置规则涵盖最危险的几类操作：

  • 对 /、~ 或主目录执行 rm -rf
  • sudo
  • git push --force（--force-with-lease 不算）
  • DROP TABLE、DROP DATABASE、TRUNCATE TABLE
  • 把网络下载的内容直接丢给 shell 执行，例如 curl … | sh
  • mkfs、dd if= 这类直接写入磁盘的命令

这些内置规则可以编辑或移除，你也可以加上自己的规则。

白名单命中，就不用等 AI

有些命令你每天都在按「允许」，例如跑测试或 build。把它们加进白名单，下次命中时，手机自己就决定要按哪个键，不用等 AI，也不花 API 用量。

「自动回复」模式下，你还可以对单个会话开启「允许此会话中的所有命令」。这样会跳过 AI 判断，黑名单照样有效，会话结束就自动关掉。

白名单命中了，但画面上找不到明确又安全的键时，一样交给你。

AI 能决定什么，不能决定什么？

黑名单和白名单都没命中的提示，才会发给 AI。它看到的是脱敏过的画面，加上你写的主要意图，也就是你这次要 agent 做什么，例如「修好登录页的测试」。

你可以选两种引擎：

  • JEV 决策引擎（通过 OpenRouter 或 TypeSafe）：专为终端里的提示设计，响应快。判断分三级：纯读取的安全操作允许；符合主要意图的命令允许；其余不相关、看不懂或风险较高的，全部交给你。看起来可疑或像恶意注入的内容会直接拒绝。
  • OpenAI 兼容的 LLM：OpenAI、OpenRouter，或是你自己搭在本地的模型都可以。

AI 的结论只有三种：允许、拒绝、不确定。只有「允许」会继续往下走，而且它必须明确指出要按画面上的哪一个选项。「永远允许」「不要再问」这类永久授权，它不会选。

顾问只给建议，自动回复帮你按

每个会话可以分别选模式：

  • 顾问（默认）：只给建议。画面上方会弹出提示，告诉你它建议按什么，旁边有「采纳」按钮，按下去才会发送。
  • 自动回复：判断为允许时直接帮你按，并弹出提示告诉你它按了什么。

不管哪一种模式，发送按键之前都会再看一下画面：提示换了、选项顺序变了，或是光标不在目标上，就不发。判断要花几秒，这几秒之内画面可能已经变了，多这一次确认，就是为了不要按到错的选项。

自动回复发送一个键之后，同一个会话会先停 3 秒，才会再发下一个。

哪些情况一定交回给你？

  • 命中黑名单。
  • AI 判断为拒绝或不确定。
  • 看不出这个提示该按哪个键。
  • 要选的是「永远允许」这类永久授权。
  • 发送前发现画面已经变了。
  • 敏感信息脱敏失败。

交给你的时候，Agentmux 会照平常的方式提醒你，就跟没开审查时一样。

要怎么打开它？

开始之前先准备好其中一种：

  • JEV 引擎的 API key，通过 OpenRouter 或 TypeSafe 获取。
  • 你自己的 OpenAI 兼容 LLM 端点，例如 OpenAI 的 API，或搭在自己电脑上的模型。
  1. 到「设置」→「AI 自动权限审查」把开关打开。第一次会看到数据共享的说明，按下同意之后，会直接带你进入「高级设置」。
  2. 在「高级设置」选择引擎、填入你的 API key，按「测试 AI 端点连接」确认可以用。
  3. 回到设置页，在「自动权限审查模式」选默认模式（先选「顾问」就行），再写下你的主要意图。
  4. 连到服务器、启动 agent，新开的标签页就会套用默认模式。要调整单个会话的模式或主要意图，点终端工具栏上的自动权限审查按钮。在那里也可以开启「使用我最近的提示」，让主要意图跟着你在这个标签页发送的每一条提示更新。

先用顾问模式跑几天，看看它的建议合不合你的习惯，再考虑对特定会话开启自动回复。

哪些数据会离开你的设备？

离开设备的只有两样：脱敏过的画面片段，和你的主要意图。它们送到你自己设置的 AI 服务，用的是你自己的 API key。开启「使用我最近的提示」之后，你在那个标签页发送的提示会成为主要意图，也一起发出。Agentmux 不提供也不经手任何 AI 服务。每次判断的记录只存在你的设备上，可以在审核记录里查看或清除。模型的推理内容不会保存。

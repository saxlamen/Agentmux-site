tmux command cheat sheet for SSH

On this page

  2. Windows and panes

Start a named tmux session with tmux new -s work, detach without stopping it using Ctrl+b d, list running sessions with tmux ls, and reattach later with tmux attach -t work. Every command below works over SSH on macOS and Linux.

This page is the quick reference for what tmux does and why agents need it. Bookmark the commands you type most, or skip typing prefix chords altogether when connecting from a phone.

Sessions: create, list, attach, detach

A session is the unit that survives an SSH drop. Name every long-running session after the repository or task so tmux ls stays readable.

Goal Command Notes
Start a named session tmux new -s work Creates session work and attaches immediately
Attach or create if missing tmux new -As work Safe single command to use in scripts or shortcuts
List active sessions tmux ls Shows session names, window counts, and attach state
Reattach to a session tmux attach -t work Short form: tmux a -t work
Detach and leave it running Ctrl+b d Returns to your outer shell; processes keep running
Rename current session Ctrl+b $ Type the new name and press Enter
Kill a finished session tmux kill-session -t work Stops all windows and panes inside work

Windows and panes

Press Ctrl+b, release both keys, then press the command key. Inside a session, windows act like tabs and panes split one window into tiles.

Action Shortcut
New window Ctrl+b c
Next / previous window Ctrl+b n / Ctrl+b p
Rename current window Ctrl+b ,
Split pane top / bottom Ctrl+b "
Split pane left / right Ctrl+b %
Move between panes Ctrl+b then arrow key
Zoom or unzoom current pane Ctrl+b z
Close current pane exit or Ctrl+d

On a phone screen, separate sessions or zoomed panes (Ctrl+b z) are easier to read than side-by-side splits.

Scrolling and copy mode

Normal terminal scrollback does not work inside tmux until you enter copy mode or enable mouse support.

  • Enter scroll / copy mode: press Ctrl+b [, then use arrow keys, PageUp, or / to search backward.
  • Exit copy mode: press q or Esc to return to the live prompt.
  • Switch sessions interactively: press Ctrl+b s for a list of sessions you can pick with arrow keys.

A minimal ~/.tmux.conf for SSH and mobile

Add these four lines to ~/.tmux.conf on your host, then reload with tmux source-file ~/.tmux.conf:

set -g mouse on
set -g history-limit 10000
set -sg escape-time 10
set -g focus-events on
  • mouse on lets touch scrolling and pane taps work over SSH.
  • history-limit 10000 keeps enough lines to inspect long agent diffs and test output.
  • escape-time 10 removes the noticeable lag after pressing Esc in Vim or CLI agents.
  • focus-events on lets editors and terminal tools detect when you switch back to a pane.

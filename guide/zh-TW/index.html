Agentmux 指南

我沒開過終端機

會用 AI 寫 code，但沒碰過 SSH。從頭建立整套心智模型。

  1. 你的 AI 應該在你睡覺時工作
  2. 為什麼不是 Cursor / VS Code
  3. 為什麼最強的 coding agent 都住在終端機裡
  4. 一條通往另一台電腦的加密隧道
  5. 讓 agent 在你關掉手機後繼續跑
  6. 不要對公網開 port
  7. 為什麼不是 Termius / Blink
  8. 15 分鐘，讓你的 agent 開始整晚工作

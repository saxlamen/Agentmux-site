名前付きセッションは tmux new -s work で作成し、Ctrl+b d で処理を止めずにデタッチ、tmux ls で一覧表示、tmux attach -t work で再接続します。以下のコマンドは macOS と Linux の SSH 接続先でそのまま使えます。

このページは tmux の仕組み解説 に対応した早見表です。よく使うコマンドだけ控えておくか、スマホからならプレフィックスキーを打たずにタップ操作で切り替えられます。

セッションの作成・一覧・再接続・デタッチ

SSH が切れてもサーバー側に残る単位がセッションです。tmux ls で見分けやすいよう、リポジトリ名や作業名を付けておきます。

目的 コマンド 補足
名前付きセッションを開始 tmux new -s work work を作成してすぐアタッチする
あれば接続、なければ作成 tmux new -As work スクリプトやショートカットに入れやすい1行
稼働中セッション一覧 tmux ls セッション名・ウィンドウ数・接続状態を表示
既存セッションに再接続 tmux attach -t work 短縮形：tmux a -t work
実行したままデタッチ Ctrl+b d 元のシェルへ戻り、裏でエージェントは動き続ける
現在のセッション名を変更 Ctrl+b $ 新しい名前を入力して Enter
不要なセッションを終了 tmux kill-session -t work work 内のウィンドウとペインをすべて閉じる

ウィンドウとペインの操作

Ctrl+b を押して離してから、次のキーを押します。セッション内ではウィンドウがタブ、ペインが画面分割に相当します。

操作 ショートカット
新規ウィンドウ作成 Ctrl+b c
前後のウィンドウへ移動 Ctrl+b p / Ctrl+b n
現在のウィンドウ名を変更 Ctrl+b ,
上下にペイン分割 Ctrl+b "
左右にペイン分割 Ctrl+b %
ペイン間のフォーカス移動 Ctrl+b のあとに矢印キー
現在のペインを拡大 / 解除 Ctrl+b z
現在のペインを閉じる exit または Ctrl+d

スマホの狭い画面では、左右分割よりもセッションを分けるか Ctrl+b z で単一ペインを拡大する方が読みやすくなります。

スクロールとコピーモード

tmux 内では通常の端末スクロールが効かないため、コピーモードに入るかマウス設定を有効にします。

  • スクロール / コピーモードに入る：Ctrl+b [ を押し、矢印キーや PageUp、/ で過去ログを遡ります。
  • コピーモードを抜ける：q または Esc で入力行に戻ります。
  • 一覧からセッションを選ぶ：Ctrl+b s を押すと矢印キーでセッションを切り替えられます。

SSH・スマホ向けの最小 ~/.tmux.conf

接続先マシンの ~/.tmux.conf に次の4行を追加し、tmux source-file ~/.tmux.conf で反映します。

set -g mouse on
set -g history-limit 10000
set -sg escape-time 10
set -g focus-events on
  • mouse on：SSH 経由でもタッチスクロールやペインタップが有効になります。
  • history-limit 10000：エージェントの長い差分やテスト出力を遡れる行数を確保します。
  • escape-time 10：Vim や CLI エージェントで Esc を押したときの待ち時間をなくします。
  • focus-events on：ペインに戻ったことをエディタ側へ通知します。

スマホでプレフィックスキーを省略する

スマホのソフトウェアキーボードで毎回 Ctrl+b を打つのは手間がかかります。Agentmux は接続時に稼働中の tmux セッションを一覧表示し、1タップで再接続できます。14日間の全機能トライアル後は無料のシングルサーバープランを利用でき、最初の設定は セットアップウィザード から進められます。
